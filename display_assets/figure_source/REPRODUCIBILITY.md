# Tables and figures

`build_assets.py` reads the existing result CSV files directly from `audit/`, `expected/posthoc/`, and `results/` and generates eleven tables and six figures. The `--tables-only` option writes tables and value records without writing figures. Use `--figure repeat_increments` to generate all tables and Figure 1 only. Figure 1 panel titles name the methods; the caption identifies which analyses were preregistered and which were exploratory. The two cohort tables are computed from saved eligibility, participant and quality-control records. The identifier crosswalk is generated from method definitions in the script. No ready-made tables or figures are required. No model is fitted and no signal control is generated by this command.

Run `python -B reproduce.py figures --output ../reproduction` or the corresponding `tables` command from the repository root. Outputs are written under `<output>/display_assets/`.

The plotting environment uses Python 3.14.3, NumPy 2.3.4, pandas 2.3.3, and Matplotlib 3.10.7. `ASSET_VALUES.json` records input hashes, displayed table values, plot values, display locations, cohort summaries and the identifier crosswalk. Regenerated PDF/SVG files may have different hashes because of rendering metadata. Compare their values, labels, axes and visible content. The package does not build the full article or supplement.

Main Table 1 reports cohort and device descriptions without group-comparison tests. Supplementary Table S1 reports participant flow. Main and supplementary performance tables use the same saved repeat estimates; the first three non-EEG rows have no EEG-increment entry. Main Table 3 draws the six specified reference/adjusted EEG contrasts directly from `expected/posthoc/results/comparison_summary.csv`, with each adjusted EEG model compared against the baseline containing the same covariates. The full 35-comparison table remains Supplementary Table S6. Main Figure 3 shows component comparisons; Supplementary Figures S1, S2, and S3 show calibration, participant-level loss changes, and coefficients, respectively.

Absolute performance and paired differences use four decimal places, rounded from saved results. Fourier-phase contrast differences use five decimal places throughout their table so that the smallest signed differences do not round to zero. A displayed difference is not obtained by subtracting rounded table cells. Ages use two decimals, with sample standard deviations (`ddof=1`); counts remain integers. Axis tick labels use fewer decimal places for readability; they indicate the scale rather than individual estimates. Computational model names remain in the data schema; human-readable names appear in figures and tables.

## Analysis settings

These settings were used to compute the saved results. The figure and table commands read those results without repeating the analyses.

- Runtime: Python 3.14.3; NumPy 2.3.4; pandas 2.3.3; SciPy 1.16.3; scikit-learn 1.8.0. Float64 calculations; root split seed 20260824125.
- Predictive models: L2 logistic regression, unpenalized intercept, no class weights, `lbfgs`, tolerance `1e-6`, maximum 1,000 iterations. The computational-failure rule allowed one otherwise identical retry with 10,000 iterations; the reported predictive fits did not require it.
- Regularization values and tie rules are in Supplementary Section S4. All final inputs were finite. The expanded-spectral code includes a missing-value rule that was not needed here: it replaces nonfinite values with the training-column median and rejects a block if any training column has more than 10% missingness.
- Resampling: `scipy.signal.resample_poly(up=1, down=2, window=('kaiser', 5.0), padtype='constant')` for native 256-Hz data. Covariance-band filtering: fourth-order Butterworth second-order sections with `sosfiltfilt` along time, separately within continuous segments, followed by the original accepted-window selection.
- Phase controls: for each participant and zero-based dataset index, the first eight SHA-256 bytes of the UTF-8 string `20260920|participant_id|index`, interpreted as a little-endian integer, seed NumPy's default random generator. Phases are independent across frequency bins, channels, and windows. All generated controls are included.
- Feature feasibility checks: raw phase-lag, entropy/Hjorth, and spectral-state matrices had 273, 9, and 27 finite columns. The full-cohort centered phase-lag matrix had rank 91 per band; this is distinct from training ranks of 59–61 in inner folds and 75–76 in outer folds. Spectral-state band blocks had rank 9 in all training partitions, above the retained component count.
- Original control implementation checks: reconstructed regional spectral and entropy/Hjorth features agreed to maximum absolute errors of `4.44e-16`; the vectorized entropy/Hjorth calculation agreed to `2.22e-16`; maximum relative Fourier-magnitude reconstruction error was `4.56e-16`. The algebraic logit decomposition error was `8.53e-14`. These are numerical implementation checks, not evidence of predictive utility.
- Scalar calibration: original BFGS estimates and flags remain in `CALIBRATION_RESULTS.csv`. Table S5 uses the separately documented post-hoc Newton solutions in `CALIBRATION_NUMERICAL.csv`. Newton iteration checks a maximum score residual of `1e-8` and a positive Hessian; an independently initialized hybrid root solver must agree within `1e-7`. The offset-only CITL estimator and predictive probabilities are unchanged.
- Fixed-OOF resampling: 5,000 paired participant draws, with models and predictions held fixed, are supplied as a post-hoc descriptive analysis. The exact deterministic seed schedule and participant ordering are in `results/numerical_followups/FIXED_OOF_SPECIFICATION.json` (relative to the repository root). No significance tests were performed for these ranges.

The figures and tables use the saved results. Model reproduction can show differences in intermediate scores for unselected candidates; the affected rows are recorded for each run. See [reproduction limits](../../docs/REPRODUCTION_LIMITS.md) for their interpretation. Figure and table generation does not repeat those fits.
