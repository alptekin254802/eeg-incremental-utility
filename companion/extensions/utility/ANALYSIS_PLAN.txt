C. CONTROLLED SIMULATION
20 independent simulation replicates, n_train={96,192,384}, four generating scenarios. Seven baseline predictors B are independent standard normal; nine residual predictors E are independent standard normal. Observed EEG proxies Z_j=0.7*B_(j mod 7)+sqrt(0.51)*E_j. Baseline latent score eta=-0.3+0.8*B1-0.6*B2+0.4*B3. Participant labels are Bernoulli with the specified probability; no repeated windows.
Scenarios fixed before fitting:
  redundant: p=expit(eta); EEG contains no conditional information beyond B.
  complementary_linear: p=expit(eta+0.8*E1).
  complementary_nonlinear: p=expit(eta+0.9*(E1^2-1)/sqrt(2)).
  acquisition_association: p=expit(eta); draw device D with P(D=1|Y=1)=0.8 and P(D=1|Y=0)=0.2. Add (2D-1) to residual E1..E3 before constructing Z. D is not a predictor in the fitted models. Assess both the same association and a shifted assessment where D~Bernoulli(0.5) independently of Y, holding B/E/Y fixed. This is a constructed distribution shift, not a causal model inferred from BALLADEER.
Within each scenario/replicate, training sizes are nested prefixes of 384 simulated individuals. Generate a separate assessment set of 4096 individuals, independent of training, shared across matched learners and sizes. Base seed 20261111; SeedSequence([base,scenario_index,replicate,0/1]) for training/test respectively. Simulation replicates, not cross-validation folds, are the Monte Carlo replication unit.
Fit baseline B and augmented [B,Z] using logistic regression and RBF SVM with the same grids as A. StandardScaler is learned separately in each inner training fold. Five stratified inner folds select by pooled log loss (seed 20261113+replicate); refit on all simulated training rows. No training-set feature/label selection; no outer CV because the simulated independent test set is available. Do not tune signal strength after seeing results.
Retain all tuning, all independent-test predictions, absolute metrics and paired differences for every cell. For the three non-device scenarios, compute conditional Bayes probabilities and the theoretical conditional-information benchmark on test covariates; the baseline marginalizes unobserved E using 80-point Gauss-Hermite quadrature. The nonlinear term is the centered squared normal, not an empirical EEG mechanism. For the device-associated IID test compute the exact two-component Gaussian mixture posterior; the shifted assessment's Bayes EEG increment is zero. These benchmark quantities describe the generating mechanisms, not achieved classifier performance.
Report mean and Monte Carlo standard error over the 20 independent replicates, individual replicate values, and the fraction of positive increments as a descriptive frequency, NOT a significance-test detection rate. Population-information benchmarks and finite-sample learned increments are different quantities. Expected fitting calls: 27,360 (240 training samples x [2*5*5+2*6*5+4 final fits]); all five assessment conditions retained, including both device conditions.
