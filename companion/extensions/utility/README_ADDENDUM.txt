Exploratory extension reproducibility addendum - 1 November 2026

Purpose and status
These analyses were planned after the original pediatric study and device-transfer findings were known. They are not part of the original preregistration and are not included in archived version 1.1.0. ANALYSIS_PLAN.txt and EXTERNAL_ANALYSIS_PLAN.txt, with their hash locks, precede their respective new fits. All planned learner, representation, size, simulation, and adult-data comparisons are retained regardless of direction.

Dependency and software
Use the extracted computational release version 1.1.0 (DOI 10.5281/zenodo.23199244). Its frozen participant features, targets, partitions, and representation builders are read only. No raw EEG extraction or new download is needed to reproduce this addendum. Software: Python 3.14.3, numpy 2.3.4, pandas 2.3.3, scipy 1.16.3, scikit-learn 1.8.0; matplotlib and threadpoolctl support plotting and thread limits. The archived release's dependencies also apply.

Reproduction into separate directories
Replace RELEASE with the extracted archived release and REPLAY_* with new empty output directories. Run from this addendum root:
python -B code/portable_reproduce.py empirical --release-root RELEASE --output-root REPLAY_EMPIRICAL --workers 4
python -B code/portable_reproduce.py simulation --release-root RELEASE --output-root REPLAY_SIMULATION --workers 4
python -B code/portable_reproduce.py external --release-root RELEASE --output-root REPLAY_ADULT
Run these sequentially to keep at most four fitting workers active. The wrapper rejects nonempty output directories. --first-only runs one diagnostic task for empirical/simulation; it is not a full reproduction. The original run_extension.py and run_external.py are retained. The wrapper changes output routing, not estimators, grids, splits, or scoring.

To rebuild the complete summary tables and vector figures from supplied outputs:
python -B code/summarize_extension.py empirical simulations external
To regenerate the manuscript tables and copy the figures, replacing MANUSCRIPT with a separate manuscript working copy:
python -B code/build_extension_assets.py --manuscript MANUSCRIPT
These last two commands intentionally regenerate derived display artifacts, not input data or fitted predictions.

File dictionary
results/empirical_v2/: 200 outer-fold/training-size/adjustment tasks. SPLIT lists participants and inner partitions; TUNING retains every grid score; INNER_FOLD_SCORES retains each validation-fold score; PREDICTIONS retains all fixed models and the training-selected spectral/covariance procedure; SELECTOR_CHOICES records representation choices. DONE records fit counts and checks. The v2 suffix documents a corrected reference-column name before a successful first task; the method did not change. TECHNICAL_CORRECTIONS records this and a summary-column indexing correction. The failed attempt remains in the local work archive and is not represented as a successful analysis.
reports/EMPIRICAL_*: all predictions, per-repeat absolute metrics, paired increments, and full summaries. Fraction 0.5/0.75/1 corresponds to 38/57/76-77 training participants. Adjustment 0 is unadjusted; 3 adds device and both quality covariates to both members of a pair. All larger positive or negative results are retained. Repeat spread is descriptive because participants are reused.
results/simulation/: all four scenarios x 20 independent replicates x three training sizes (240 tasks). METRICS includes both iid and shifted assessment for acquisition_association. ORACLE reports known-probability conditional-information benchmarks. SPLIT gives seeds and inner partitions. Training sets are prefixes of the SAME 384-person pool, not separate generated(size=n) calls. Test pools contain 4,096 synthetic participants. Reports retain all 600 paired learned increments, not only plotted means.
Simulation PREDICTIONS.npz in this submission archive contains every fitted probability array, every oracle probability array, test_y and train_y. Only test_B, test_E, test_D and test_shiftD are omitted to avoid storing duplicate synthetic covariates. They are exactly reconstructed by generated(scenario, replicate, 4096, 1) in run_extension.py. Original full NPZ files remain unchanged in the local analysis workspace. SYNTHETIC_ARRAY_PACKAGING.json records retained arrays and original hashes; PACKAGE_MANIFEST.json identifies every supplied file. Every retained array was compared element-for-element with its original.
results/external/: all six adult baseline/learner comparisons, complete tuning, test probabilities, missingness, dropped-column records, absolute metrics, participant increments, and 60,000 conditional bootstrap contrast rows (10,000 draws shared by all six comparisons). Intervals condition on the fitted training procedure and fixed class counts. They omit training/selection uncertainty.
reports/*VERIFICATION.json and audit/: independent metric recomputation, original logistic-reference matching, nested-subset and held-out transformation checks, deterministic replay, and oracle quadrature checks. A fixed empirical task and a fixed nonlinear simulation task reproduced all compared CSV bytes and probability arrays. All 12 adult final models reproduced probabilities exactly. A separate first-task portable simulation check also reproduced its outputs. The entire extension was not rerun twice; the full training-bootstrap was not performed.

Adult data attribution and limits
external/ contains unchanged public source files downloaded from the official OSF EWKGV repository, its metadata, download hashes, variable dictionary and original scripts. Attribution: Annika Wiebe, Benjamin Selaskowski, Martha Paskin, Laura Asche, Julian Pakos, Behrem Aslan, Silke Lux, Alexandra Philipsen, and Niclas Braun, Virtual reality-assisted prediction of adult ADHD based on eye tracking, EEG, actigraphy and behavioral indices: a machine learning analysis of independent training and test samples, Translational Psychiatry 14, 508 (2024), DOI 10.1038/s41398-024-03217-y. Data DOI: 10.17605/OSF.IO/EWKGV. Source license: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/ ; full text is in external/license_metadata.json. Derived analysis outputs are newly generated; source data bytes were not modified. Authors' original scripts were read as documentation, not executed.
The adult files preserve 50 training and 36 independent test rows. Their diagnosis verification and gaze measures differ from BALLADEER. No adult/pediatric pooling or frozen-pediatric-model external validation is claimed. Synthetic participants do not enlarge either empirical cohort. These checks support interpretation, not clinical readiness, universal EEG uselessness, equivalence, or a new algorithmic optimum.

Metric signs
Delta log loss = baseline minus EEG-augmented loss; delta Brier = baseline minus EEG-augmented score; delta AUROC = EEG-augmented minus baseline. Positive values favor EEG. All log losses use natural logarithms, with predicted probabilities clipped to [1e-8, 1-1e-8]. Display tables round to four decimal places; full-precision CSVs preserve small signed values that round to zero.
