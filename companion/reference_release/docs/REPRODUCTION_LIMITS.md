# Numerical reproduction limits

A previous run from freshly generated inputs recovered the selected models and outer-fold predictions within the stated tolerances. Some intermediate diagnostics differed, as described below. Keep these differences in mind when comparing a new run with the supplied results.

- Some inner-validation scores for the unselected regularization candidate `C=100` exceeded the `1e-7` comparison threshold. Selected regularization values and outer predictions agreed. The `1e-7` tolerance is unchanged. `models` saves every row exceeding it to `INTERMEDIATE_SCORE_DIFFERENCES.csv` and sets `passed` to `false`. It can finish with the warning `RESULTS_REPRODUCED_WITH_INTERMEDIATE_DIFFERENCES` only when the differences concern unselected `C=100` scores and the validity flags, ranks, selected models, diagnosis metrics and outer-fold probabilities all agree. Other mismatches stop the command. Add `--strict-intermediates` to stop on these `C=100` differences as well.
- Scalar calibration estimation can terminate with precision-loss warnings. The set of successful fits differed in the replay; estimates for fits successful in both runs agreed, and the reliability-bin results agreed. The original scalar calibration results remain archived with their failures. The supplement also reports a post-hoc calculation using `calibration-numerical`. It solves the same likelihood with a different numerical method while preserving the predictive probabilities and reliability bins.
- For participants excluded before complete feature extraction, some diagnostic fields used zero in one record and an unavailable value in another. Eligibility decisions were unchanged. Missing diagnostic values should not be interpreted as measured zeros.
- Historical participant predictions and selected regularization values for the diagnosis-status sensitivity were not included in the original result archive. Its saved repeat-level metrics provide the released numerical reference; a new run can produce participant predictions, but their historical identity cannot be checked against an absent reference.

File checks, tests and figure/table generation cover only parts of the workflow. To rerun the analysis from raw data, follow the [reproduction guide](REPRODUCIBILITY.md), which explains the inputs used by each command. Use the same prespecified comparison tolerances when checking results in a new environment.
