Raw recordings are obtained separately from the provider. This companion includes derived feature tables and pseudonymous participant-level reference results for reproducing the study. These materials retain the source-data attribution and applicable CC BY 4.0 terms; the code's MIT license does not relicense the underlying data. The transformations are documented in the accompanying Methods and Supplement, and implemented in the released preprocessing and analysis modules.

Use the required input layout and recorded file digests in the reproduction instructions. The latest provider version alone is not evidence that a local input matches the analysis data. Cite the source record when reusing the derived materials.
