# EEGNet cross-fitting sensitivity, 2026-11-05

Exploratory design specified before evaluating these heads. Reuse the saved
250 inner encoders in companion/extensions/eegnet/results. No encoder training.
Use each encoder's own final training-head logit, computed from its saved
participant-mean embeddings, because embedding coordinates differ by encoder.
Apply saved normalization and weights to the frozen float32 accepted windows
to obtain outer-test logits. Check cached hashes and train/assessment rosters.

Primary sensitivity: for each outer fold and each of its five inner encoders,
fit a baseline and baseline-plus-logit head ONLY on that encoder's inner-valid
participants (about 15), all absent from its encoder training. Tune each head's
C using stratified CV restricted to that head-training subset, with up to five
folds (minimum class count if smaller), pooled log loss and the original C grid.
Scale only in the corresponding head-training data. Apply the five paired
heads to the untouched outer test set and average probabilities. Thus neither
head fitting nor tuning receives any EEG score from an encoder that saw that
participant, and head-C validation labels never trained the relevant encoder.
This changes the architecture to a split ensemble and reduces head-training
size; its matched split-ensemble baseline must be reported, alongside the
recorded full-training baseline comparison as an additional diagnostic.

Secondary sensitivity, fixed before seeing outcomes: pool the five inner-valid
logits into one out-of-fold score for each outer-training participant. Fit
paired heads with fixed C=1 (no tuning, avoiding cross-fitted-score tuning
contamination). For assessment, apply this head separately to each of the
five inner-encoder test logits, then average probabilities. Each training
score excludes its own participant. Scores for other participants can depend
on that participant's training label, as in ordinary cross-fitting; the outer
test remains excluded from every encoder and every head.

Use identical seven baseline variables and logistic implementation as the
primary study. Report all designs, metrics, positive LL repeats, conditional
10000-draw class-stratified participant ranges, and limitations. These ranges
hold all predictions fixed and omit training uncertainty. Compare to the
original embeddings result descriptively, not as an isolated causal estimate
of self-fitting bias. Save all outputs separately; do not write them into
the manuscript. Plans and source hashes accompany results.
